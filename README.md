## The entry

> v1.4.2: fixed a bug where the brain replayed an embarrassing moment from 2011 at 3 a.m. instead of sleeping.

One line, 108 characters: a software patch note for a bug in human biology —
the brain replaying an old embarrassing moment at 3 a.m. instead of letting
you sleep. Written in the terse register of a real release note.

## How it works

`main.py` (Python standard library only) writes the patch note to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It validates
the entry first: a single line of 1–160 characters, no extra whitespace.

## Run it

```sh
python3 main.py
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
